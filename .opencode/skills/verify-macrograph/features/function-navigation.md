# Function navigation and split constants

## User path

1. Open the playground.
2. Select the **Functions** navigation tab.
3. Create a function.
4. Confirm it appears in the function list.
5. Confirm the **Constants** pane remains visible below a horizontal resize divider.

## Verification

`pnpm verify:playground:function-navigation` asserts this path in an isolated Chromium profile and records the resulting editor screenshot and server log.
